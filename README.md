# Ellie English — 설치 안내

폰 홈 화면에 아이콘으로 깔리는 앱입니다. 설치할 앱스토어는 없고, 파일을 인터넷에 올린 뒤
폰 브라우저에서 "홈 화면에 추가"를 누르면 끝입니다.

순서는 셋으로 나뉩니다.

1. **올리기** — GitHub Pages에 파일 올리기 (10분). 여기까지만 해도 앱은 완성입니다.
2. **깔기** — 폰 홈 화면에 추가 (1분).
3. **공유** — 부부가 같은 카드를 보게 Firebase 붙이기 (15분). 나중에 해도 됩니다.

3번을 안 하면 카드가 각자 폰에만 저장됩니다. 나머지 기능은 전부 그대로 돌아갑니다.

---

## 1. GitHub Pages에 올리기

1. github.com 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름은 `yeonwoo-cards`, **Public**으로 두고 **Create repository**
   (Private은 GitHub Pages 무료 플랜에서 안 됩니다)
3. 다음 화면에서 **uploading an existing file** 링크 클릭
4. 이 폴더 안의 **내용물 전체**를 끌어다 놓으세요.
   `index.html`, `app.js`, `seed.js`, `firebase-config.js`, `sw.js`,
   `manifest.webmanifest`, `README.md`, 그리고 `icons` 폴더 통째로.
   ⚠️ `yeonwoo-app` 폴더 자체가 아니라 **그 안의 파일들**이 최상단에 있어야 합니다.
5. 아래 **Commit changes** 클릭
6. 저장소 상단 **Settings** → 왼쪽 **Pages**
7. Source 를 **Deploy from a branch**, Branch 를 **main / (root)** 로 두고 **Save**
8. 1~2분 뒤 같은 화면 위쪽에 주소가 뜹니다:
   `https://<아이디>.github.io/yeonwoo-cards/`

이 주소를 폰으로 열어 보세요. 앱이 뜨면 성공입니다.

> 나중에 앱을 고칠 때는 GitHub에서 파일을 열어 연필 아이콘으로 수정하고 Commit 하면
> 1분쯤 뒤 반영됩니다. 화면이 안 바뀌면 `sw.js` 첫 부분의 `ellie-english-v2` 을
> `v2`, `v3` 으로 올려 주세요. 브라우저가 옛 파일을 붙들고 있어서 그렇습니다.

## 2. 홈 화면에 추가하기

**아이폰 (사파리에서 열어야 합니다. 크롬은 안 됩니다)**
1. 위 주소를 사파리로 열기
2. 아래 가운데 **공유 버튼**(↑) 누르기
3. 목록을 내려서 **홈 화면에 추가**
4. 이름 확인하고 **추가**

**안드로이드 (크롬)**
1. 위 주소를 크롬으로 열기
2. 오른쪽 위 **⋮** → **앱 설치** 또는 **홈 화면에 추가**
   (앱 안 설정 탭에 "홈 화면에 추가" 버튼이 떠 있으면 그걸 눌러도 됩니다)

이제 아이콘을 누르면 주소창 없이 전체 화면으로 열리고, 비행기 모드에서도 열립니다.

## 3. 부부 공유 붙이기 (선택)

카드를 두 폰이 같이 보게 하려면 Firebase가 필요합니다. 무료 범위 안에서 충분합니다.

### 3-1. 프로젝트 만들기
1. console.firebase.google.com 접속 (구글 계정으로 로그인)
2. **프로젝트 만들기** → 이름 `yeonwoo-cards` → 애널리틱스는 **끄기** → 만들기

> **메뉴에서 헤매지 마세요.** Firebase 콘솔은 왼쪽 메뉴 구조가 종종 바뀝니다.
> 예전에 있던 **빌드** 카테고리는 지금 없습니다. 어느 화면이든 왼쪽 위 **제품 검색**에
> 이름을 쳐서 들어가는 게 가장 확실합니다. 아래 주소의 `yeonwoo-cards` 부분만
> 본인 프로젝트 이름으로 바꿔도 바로 갑니다.

### 3-2. 익명 로그인 켜기
1. **제품 검색**에 `Authentication` 입력 → 들어가서 **시작하기**
   (메뉴에서는 **보안** 카테고리 안에 있습니다)
   바로 가기: `console.firebase.google.com/project/yeonwoo-cards/authentication/providers`
2. **Sign-in method** 탭 → 목록에서 **익명** → **사용 설정** 켜고 **저장**

### 3-3. 데이터베이스 만들기
1. **제품 검색**에 `Firestore` 입력 → **데이터베이스 만들기**
   (메뉴에서는 **데이터베이스 및 스토리지** 안에 있습니다. Realtime Database 말고 **Firestore Database**)
   바로 가기: `console.firebase.google.com/project/yeonwoo-cards/firestore`
2. 위치는 `asia-northeast3 (서울)` 권장
3. 모드는 **프로덕션 모드**로 시작 (규칙은 다음 단계에서 바꿉니다)

### 3-4. 설정값 가져와 붙여넣기
1. 왼쪽 **설정 → 프로젝트 설정** → 아래로 스크롤 **내 앱**
   바로 가기: `console.firebase.google.com/project/yeonwoo-cards/settings/general`
2. **웹(`</>`)** 아이콘 클릭 → 앱 닉네임 아무거나 → **앱 등록**
   (이걸 해야 진짜 값이 생깁니다. 건너뛰면 채워 넣을 값 자체가 없습니다)
3. GitHub 저장소에서 **`firebase-config.js`** 를 열고 연필 아이콘 클릭
4. 파일 **전체를 지우고** 아래 틀을 붙여넣기
5. 콘솔에 나온 값을 **따옴표 안에만** 하나씩 옮겨 적고 Commit

```js
export const FIREBASE_CONFIG = {
  apiKey:            "",
  authDomain:        "",
  projectId:         "",
  storageBucket:     "",
  messagingSenderId: "",
  appId:             ""
};

export const FIREBASE_VERSION = "12.18.0";
```

> ⚠️ **여기서 가장 많이 막힙니다.** 콘솔에 보이는 `const firebaseConfig = { ... };`
> 블록을 통째로 복사해 붙여넣으면 선언이 두 번 겹쳐서 앱이 아예 안 뜹니다.
> 붙여넣지 말고 **값만 옮겨 적으세요.**
> `apiKey` 는 `AIza` 로 시작하는 39자 문자열입니다. 점 세 개(`...`)가 들어간
> 값을 적으면 안 됩니다 — 그건 설명서의 예시 표기입니다.

> 값을 비워 두어도 앱은 잘 돌아갑니다. 공유만 꺼진 채로 카드는 그대로 쓸 수 있으니
> 막히면 빈 채로 두고 나중에 채워도 됩니다.
> 그리고 `apiKey` 는 비밀번호가 아닙니다. 공개돼도 되는 값이고,
> 실제 접근 제어는 다음 단계의 보안 규칙이 합니다.

### 3-5. 보안 규칙 넣기
1. **Firestore Database → 규칙** 탭
2. 내용을 전부 지우고 아래를 붙여넣은 뒤 **게시**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{familyId}/cards/{cardId} {
      allow read, write: if request.auth != null
        && familyId.size() >= 10;
    }
  }
}
```

로그인한 사람 중 **가족 코드를 아는 사람만** 그 가족의 카드에 닿습니다.
코드는 12자리 무작위 문자라 찍어서 맞히기는 사실상 불가능합니다.
다만 코드를 아무에게나 공유하지는 마세요.

### 3-6. 코드 만들고 배우자 초대
1. 앱을 새로고침하고 **설정** 탭 열기
2. **가족 코드 만들기** 누르기
3. **참여 링크 복사** 를 눌러 배우자에게 카톡으로 보내기
4. 배우자가 그 링크를 열고 "참여할까요?"에 확인 누르면 끝

설정 탭의 점이 초록색 **공유 중**으로 바뀌면 성공입니다.
이제 한쪽에서 담은 카드가 다른 쪽 폰에 바로 뜹니다.

## 쓰는 법

- **담기** — 마이크 누르고 그냥 말하면 글로 받아 적힙니다. 고를 것이 없어 두 번만 누르면 끝납니다.
  상황은 나중에 **모아보기**에서 카드를 펼쳐 붙일 수 있습니다.
- **복습** — 오늘 볼 카드만, **매번 순서를 섞어서** 보여 줍니다. 위쪽 보라 카드가 오늘 진도입니다. "알겠어요"를 누를수록 간격이 벌어집니다
  (1일 → 3일 → 7일 → 16일 → 35일 → 90일). 복습 진도는 두 분이 각자 따로 갑니다.
- **모아보기** — 전체 목록, 상황별 필터, 삭제.
- **설정** — 공유 상태, 영어 채우기, 전체 내려받기.

### 인터넷이 안 될 때

카드는 **언제나 폰에 먼저** 저장됩니다. 공유가 켜져 있으면 그 다음에 업로드를 시도하고,
지하철이나 비행기 모드라 실패하면 **업로드 대기 줄**에 남습니다.
설정 탭에 "폰에 저장됨 · N건이 업로드를 기다리는 중"으로 표시되고,
연결이 돌아오면 자동으로 올라갑니다. 앱을 껐다 켜도 대기 줄은 그대로 있습니다.

같은 카드를 두 사람이 각자 오프라인에서 고쳤다면 나중에 올라온 쪽이 남습니다.
거의 생기지 않는 일이지만 원리는 그렇습니다.

### 기본 카드 바꾸기

`seed.js` 안에 장소별 기본 문장이 들어 있습니다. 형식은 한 줄에

```
[상황, 영어, 한국어, 알아둘 점, 영어 예문, 한국어 예문]
```

고치거나 줄을 더한 뒤 파일 위쪽의 `SEED_VERSION` 숫자를 올리면,
이미 쓰고 있는 폰에도 **새로 추가된 카드만** 다음 실행 때 얹힙니다.
직접 지운 기본 카드는 다시 살아나지 않습니다.

### 영어는 어떻게 채워지나

새로 담은 카드는 "영어 대기" 상태입니다. 설정 탭에서:

1. **대기 중인 표현 복사하기** 누르기
2. Claude에 붙여넣기
3. 돌아온 JSON을 **Claude가 준 JSON 붙여넣기** 칸에 넣고 **채우기** 누르기

카드가 완성되고 복습 목록에 올라갑니다.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 마이크 버튼이 없다 | 아이폰은 사파리에서 열어야 합니다. 없으면 키보드의 마이크 키로 받아쓰기하세요 |
| 고쳤는데 화면이 그대로다 | `sw.js` 첫 부분 `ellie-english-v2` 의 숫자를 올리고 Commit |
| 설정에 "공유 연결 실패" | 화면에 뜬 안내 문구를 보세요. 대개 익명 로그인이 꺼져 있거나 규칙이 안 게시된 경우입니다 |
| 콘솔 메뉴에 그 항목이 없다 | Firebase 콘솔은 메뉴가 종종 바뀝니다. 왼쪽 위 **제품 검색**에 이름을 치거나 위에 적어 둔 바로 가는 주소를 쓰세요 |
| 홈 화면 추가가 안 보인다 | 아이폰은 **사파리**, 안드로이드는 **크롬**에서만 됩니다 |
| 카드가 사라졌다 | 설정 → 카드 전체 내려받기로 백업해 두세요 |
